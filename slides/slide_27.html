Грабли и фикс

SQL 
TTL toDateTime(ObservedTimestamp) + toIntervalDay(LogTTL)
SETTINGS ttl_only_drop_parts = 0

Грабли

По умолчанию ttl_only_drop_parts = 1 — партиция живёт по самому долгому TTL.

Партиция с TTL=2 дня будет ждать 180 дней из-за одной записи рядом.

Решение

= 0 — не ожидать истечения всех TTL в партиции.

TTL применяется построчно, корректное хранение.

Грабли: по умолчанию ttl_only_drop_parts = 1 — партиция удаляется целиком только когда истёк TTL у всех записей. Для нашего сценария это критично: партиция с TTL=2 дня будет ждать 180 дней из-за одной записи с TTL=180 рядом. Решение — поставить ttl_only_drop_parts = 0: не ожидать истечения всех TTL в партиции, TTL применяется построчно.
