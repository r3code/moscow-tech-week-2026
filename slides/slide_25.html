TTL на уровне строки

SQL-схема ClickHouse 
CREATE TABLE logs.otel_logs (
  ObservedTimestamp DateTime64(3),
  LogTTL UInt8,
  Body String,
  Attributes Map(String, String)
) ENGINE = MergeTree
  ORDER BY (ObservedTimestamp)
  TTL toDateTime(ObservedTimestamp)
    + toIntervalDay(LogTTL)
  SETTINGS ttl_only_drop_parts = 0
Решение — встроить TTL прямо в SQL-схему на уровне строки. ClickHouse сам удаляет старые записи через TTL-выражение toDateTime(ObservedTimestamp) + toIntervalDay(LogTTL). Но есть грабли — на следующем слайде.
