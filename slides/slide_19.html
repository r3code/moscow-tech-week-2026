2 параметра Vector

Vector config 
[sources.app_log]
type = "file"
include = "/var/log/containers/*.log"

# Читать свежие логи блоками по 16 КБ
oldest_first = false
max_read_bytes = 16384
Решение — два параметра. oldest_first: false — чтобы Vector не пытался дочитать старые файлы. max_read_bytes: 16384 — чтобы читать свежие логи блоками по 16 КБ. На следующем слайде — результат.
